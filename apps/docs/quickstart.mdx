title: Quickstart

---

Needs Node 20+, pnpm, and Redis + MongoDB (Docker or local installs).

<Steps>
  <Step title="Start Redis and MongoDB">
    ```bash
    docker compose up -d
    ```
    Or run `redis-server` and `mongod` yourself.
  </Step>
  <Step title="Install and build">
    ```bash
    cp .env.example .env
    pnpm install
    pnpm build
    ```
    `packages/core` builds first; the apps import its compiled output.
  </Step>
  <Step title="Seed">
    ```bash
    pnpm cli seed --force --start now --minutes 60
    ```
    Creates indexes, the product, a sale that starts now and runs an hour, and the demo account.
  </Step>
  <Step title="Run">
    ```bash
    pnpm dev
    ```
    API on `:3000` (Swagger UI at `/docs`), worker, storefront on `:5173`.
  </Step>
</Steps>
