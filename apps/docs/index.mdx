A Fastify API, a BullMQ worker and a React storefront, with Redis on the hot path and MongoDB as the durable record, in a pnpm + Turborepo monorepo.

## What the system guarantees

- **No overselling.** One atomic Redis Lua script checks the window, the buyer and the stock, then decrements, in one round trip.
- **One unit per account.** The buyer is the account in the signed session cookie, never anything in the request body.
- **No duplicate orders.** The buyer set, a fixed queue job id per account and a unique Mongo index each stop a second order on their own.
- **Fast failure.** Redis down means a 503 in milliseconds. A saturated process sheds load before the purchase gate runs.
