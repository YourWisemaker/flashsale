# Plan product

Use when the product direction changes (new audience, new capability), not for single features.

1. Read `agent-os/product/mission.md`, `roadmap.md`, `tech-stack.md`, and `docs/PRD.md`.
2. Ask the user only what the files don't answer: who it's for, what problem, what must not break.
3. Update `mission.md` (who, problem, what done means), `roadmap.md` (Done / In progress / Open decision / Later, checkboxes), and `tech-stack.md` if the stack changes.
4. A stack change with a real alternative also gets an ADR (`.claude/skills/adr`).
5. Show the diff of the three files and stop. No code in this command.
